================================================================================
                    PRE-DEPLOYMENT CHECKLIST
================================================================================

### 1. Update URLs (Not localhost)
- [ ] `GITHUB_CALLBACK_URI` → your actual domain
- [ ] `BACKEND_URL` → your backend domain
- [ ] `CORS_ORIGINS` → your actual domains

### 2. Environment Variables (Production)
```bash
# Backend
GITHUB_CLIENT_ID=your_actual_client_id
GITHUB_CLIENT_SECRET=your_actual_client_secret
GITHUB_CALLBACK_URI=https://your-domain/api/v1/auth/github/callback
BACKEND_URL=https://your-backend-domain
WEB_PORTAL_URL=https://your-frontend-domain

# Web
GITHUB_CLIENT_ID=your_actual_client_id
GITHUB_CLIENT_SECRET=your_actual_client_secret
GITHUB_CALLBACK_URI=https://your-domain/github/callback
BACKEND_URL=https://your-backend-domain
```

### 3. CORS Configuration
In `backend/main.py`, change:
```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["https://your-frontend-domain"],  # Not "*"
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

### 4. Security (HTTPS)
- [ ] Deploy behind HTTPS/proxy (Render, Railway, etc.)
- [ ] Set `secure=True` on cookies (production)

### 5. Rate Limiting (Production Note)
- [ ] Current in-memory rate limit works for single instance
- [ ] For multiple instances, use Redis instead

### 6. Database (Production)
- [ ] SQLite works but consider PostgreSQL for production
- [ ] Or keep SQLite with proper backups
